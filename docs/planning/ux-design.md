# UX Design Planning Index

This file exists so planning workflows that discover `*ux*.md` under `docs/planning` load the UX source intentionally.

Primary UX sources:

- `docs/design/docs/design-implementation-guide.md`
- `docs/planning/design-update-plan.md`
- `docs/planning/epics.md`, Epic 10: Frontend Design System Rebuild

Use these sources together when creating or validating frontend design-system stories. The design guide defines the target UI behavior, the design update plan explains current production gaps and sequencing, and Epic 10 breaks the design work into implementation stories.
